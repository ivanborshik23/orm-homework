# Домашнее задание ORM (SQLAlchemy)

Выполнено:
- Задание 1 — модели
- Задание 2 — запрос по издателю
- Задание 3 — загрузка из JSON

### Как запустить:
1. `pip install -r requirements.txt`
2. Создать файл `.env` с данными подключения
3. Заполнить базу: `python fill_db.py`
4. Запустить: `python main.py`
